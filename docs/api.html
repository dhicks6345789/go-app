GET/api/v1/health

Health Check

Returns operational status of the service.

Responses
CodeDescriptionContent

System Info

Returns system metrics, Go version, OS/Arch, and uptime.

Responses
CodeDescriptionContent
200System statusapplication/json object { arch: string, go_version: string, mode: string, os: string, uptime: string }
